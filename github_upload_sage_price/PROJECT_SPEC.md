# SAGE-Price Model 프로젝트 명세

## 1. 프로젝트 목표

SAGE-Price Model은 **Score-weighted Asset-pricing Guided Ensemble**의 약자다.
한국어로는 **성과점수 가중 자산가격결정 앙상블 모형**이라고 설명할 수 있다.

이 프로젝트의 목표는 1년 뒤 주가를 하나의 절대 모형으로 맞히는 것이 아니라,
여러 전통 자산가격결정모형과 가치평가모형이 제시하는 기대 주가를 과거 성과에
따라 가중평균하여 최종 기대 주가를 산출하는 것이다.

최종 산식은 다음과 같다.

```text
최종 기대 주가 = Σ(모형별 기대 주가 × 모형별 성과 기반 비중치)
```

## 2. 왜 SAGE인가

SAGE라는 이름은 프로젝트의 구조를 그대로 담고 있다.

- **Score-weighted**: 과거 백테스트 성과점수로 모형별 비중치를 결정한다.
- **Asset-pricing**: CAPM, Fama-French, APT 등 자산가격결정 이론을 활용한다.
- **Guided**: 단순 평균이 아니라 검증 결과가 예측 결합을 이끈다.
- **Ensemble**: 서로 다른 관점의 여러 모형을 결합한다.

즉, SAGE-Price Model은 주가를 하나의 공식으로 단정하지 않고, 시장위험,
기업 특성, 거시경제, 배당, 회계 이익이라는 여러 관점을 함께 반영한다.

## 3. 채택 모형 5개

현재 기본 모형 세트는 다음 5개로 구성된다.

| 번호 | 모형 | 핵심 역할 |
|---|---|---|
| 1 | CAPM | 시장위험 베타를 이용해 기대수익률을 계산 |
| 2 | Fama-French 3-Factor Model | 시장, 규모, 가치 요인을 반영 |
| 3 | APT / Macro Factor Model | 금리, 환율 등 거시경제 요인을 반영 |
| 4 | DDM / Gordon Growth Model | 배당 현금흐름 기반 내재가치 추정 |
| 5 | Residual Income Model | 장부가치와 초과이익 기반 내재가치 추정 |

## 4. 모형 선택 방어 논리

5개 모형은 단순히 개수를 맞추기 위해 선택한 것이 아니다. 각 모형은 주가를
설명하는 서로 다른 이론적 관점을 대표한다.

- CAPM은 가장 전통적인 기준 모형으로, 시장위험이 기대수익률을 어떻게 설명하는지 보여준다.
- Fama-French 모형은 CAPM이 놓치는 규모와 가치 요인을 보완한다.
- APT / Macro Factor 모형은 금리와 환율 같은 거시경제 환경을 반영한다.
- DDM / Gordon Growth Model은 주식을 미래 배당의 현재가치로 해석한다.
- Residual Income Model은 배당이 적은 기업도 회계 이익과 장부가치로 평가할 수 있게 한다.

따라서 SAGE-Price Model은 시장 기반 모형과 내재가치 기반 모형을 함께 사용하여
단일 모형 의존도를 줄이고, 과거 성과에 따라 더 설득력 있는 모형에 더 큰 비중을 부여한다.

## 5. 구현 방식

1. 종목 가격과 관련 보조 데이터를 수집한다.
2. 10년 내외의 과거 데이터를 사용해 각 모형의 1년 뒤 기대 주가를 반복 예측한다.
3. 실제 1년 뒤 주가와 예측값의 차이를 비교해 모형별 성과를 계산한다.
4. 예측 오차가 작은 모형에 더 높은 비중치를 부여한다.
5. 현재 시점의 5개 모형 기대 주가를 성과 기반 비중치로 가중평균한다.
6. 최종 결과로 1년 뒤 기대 주가와 참고용 범위를 제시한다.

## 6. 최종 출력물

SAGE-Price Model은 특정 종목에 대해 다음 정보를 출력한다.

- 현재 주가
- 1년 뒤 최종 기대 주가
- 1년 뒤 예상 수익률
- 참고용 하단 가격과 상단 가격
- 모형별 기대 주가
- 모형별 백테스트 예측 오차
- 모형별 최종 비중치
- 백테스트 상세 결과

## 7. 프로젝트 의의

이 프로젝트는 자산가격결정 이론을 단순 설명에 그치지 않고 실제 데이터 기반
예측 구조로 구현했다는 점에 의의가 있다. 또한 모형별 성과를 비교한 뒤 그 성과를
가중치로 변환하므로, 주관적 판단보다 검증 결과에 기반한 예측 결합을 수행한다.

SAGE-Price Model은 투자 조언을 직접 제공하는 도구가 아니라, 전통 금융이론을
코드와 데이터 분석으로 연결한 연구 및 교육용 기대주가 산출 프레임워크다.
